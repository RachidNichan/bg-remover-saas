### Core Functionalities to Implement:

#### 1. Python AI Microservice (`/backend`):
- Create a lightweight FastAPI service.
- Use `rembg` (CPU mode, using `u2net` or `isnet-general-use` model).
- Endpoint: `POST /api/remove-bg`:
  - Receives an image (file or base64).
  - Processes it using `rembg.remove()`.
  - Returns the processed PNG image with transparent background.
- Include a simple `Dockerfile` and `requirements.txt`.

#### 2. Next.js SaaS Application (`/frontend` or root):
- **Landing Page:**
  - Modern, dark-mode hero section.
  - Interactive "Before & After" image comparison slider.
  - Drag-and-drop image upload box (max 10MB, accepts JPG/PNG/WEBP).
  - Feature highlights and pricing table.
- **Authentication & User Management:**
  - Firebase Authentication: Google Sign-in modal/page and Email/Password auth.
  - Firestore integration:
    - On user creation: assign default 3 free credits in `users/{userId}`.
    - Each background removal consumes 1 credit.
    - If credits == 0, prevent image processing and show an "Upgrade" modal.
- **Core SaaS Flow:**
  - User uploads image -> Check authentication & credits in Firestore -> Forward image to the Python FastAPI service -> Deduct 1 credit -> Display processed image with an instant "Download HD PNG" button.

#### 3. Configuration & Deployment:
- **`docker-compose.yml`**: To run both Next.js and the Python FastAPI microservice seamlessly with one command (`docker-compose up`).
- **`.env.example` & `.env`**: Containing:

  - `AI_BACKEND_URL=http://localhost:8000` (or Docker service URL).
